# D&D 5e 2024 Character Builder

A browser-based character builder and PDF character sheet exporter for Dungeons and Dragons 5th Edition (2024 rules).

**Live App:** https://birddie721.github.io/5e2024Builder/

## Features

- Select character name, species (including subraces where applicable), class, and background.
- Allocate ability scores using point buy, recommended class stats, or custom adjustments.
- Choose starting skill proficiencies and view class details as you build.
- Export a populated character sheet PDF, including a printer-friendly / playable option that omits frequently changing fields.

## Running Locally

This project is built as a static web application using HTML, CSS, and JavaScript.

1. Clone or download the repository.
2. Open `index.html` in a web browser (or serve the folder with a local static server).

## Disclaimer

This tool is intended to assist with character creation and is not a replacement for the official *Dungeons and Dragons* Player's Handbook.
